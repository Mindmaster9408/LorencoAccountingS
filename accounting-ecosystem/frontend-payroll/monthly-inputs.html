📥 Monthly Inputs Import

Load one month's variable inputs for all employees at once — overtime and short-time hours, and amounts such as advances, loans, savings and other deductions or earnings. A value in the file replaces that employee's value for the same item this month; blank or 0 changes nothing. Overtime from Attendance and short time from unpaid leave are kept. Nothing is saved until you check the file and press Save. Finalized months cannot change.
